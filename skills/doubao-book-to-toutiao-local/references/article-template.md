# 今日头条爆款成稿模板（本地 JSON 版）

## article.json 结构

```jsonc
{
  "no": 1,
  "title": "主标题（钩子式）",
  "altTitles": ["备选标题1", "备选标题2", "..."],
  "cover": "封面图提示词（2054x1600）",
  "content": [
    { "type": "text",  "content": "开头钩子（100~150字）" },
    { "type": "title", "content": "第一小节小标题" },
    { "type": "text",  "content": "案例引入段落" },
    { "type": "text",  "content": "概念拆解段落" },
    { "type": "image", "content": "插图提示词（16:9）" },
    { "type": "text",  "content": "方法/结论段落" },
    // ... 更多小节
    { "type": "text",  "content": "结尾总结 + 互动引导" }
  ],
  "goldenQuotes": ["金句1", "金句2"],
  "tags": ["#标签1", "#标签2"],
  "layoutNotes": "排版说明"
}
```

## 写作要点

1. **主标题**：数字 + 痛点/悬念 + 承诺。例："为什么你总爱错人？9个择偶心理真相，越早知道越少吃亏"。
2. **开头钩子**：100~150 字，用读者场景/痛点/反常识切入，不寒暄。
3. **正文小节**：N 节 = 该章 N 个核心议题。每节三件套：
   - 小标题：信息量前置，直接给结论，禁止"01/02"或空洞词；
   - 案例引入：书中案例转生活化叙事（"有个男生…""认识一个姑娘…"），保留具体细节；
   - 概念拆解：心理概念 + 一句大白话解释；
   - 方法/结论：2~4 条可执行建议，或金句收束。
4. **插图**：每 1~2 段一张，image 块插在对应内容之后，一图一核心；**插图之间必须间隔至少一个正文段落，不允许连续两张插图相邻**。
5. **结尾**：总结主线 + 互动引导（"这几条你中了几条？评论区聊聊"）。
6. **话题标签**：3~6 个，放 `tags` 数组。

## 字数与分段

- 正文（不含标题、提示词、标签）不低于 3500 字。
- 自然分段：段落承载完整意思单元，意思转折换段，意思连贯不拆。

## 补写策略（字数不足时的高质量扩写）

> ⚠️ **最高优先级：补写是深化内容，不是凑字数。** 字数不足 3500 字时，禁止堆砌无意义短句、重复语句、语气词；必须按以下四步流程执行，保证每一段都有信息量。

**总原则**：补写不是"往文章里塞字"，而是把这篇文章**本来就该写、但没写够**的部分补完。每补一段都要能回答：读者读完这段，多懂了什么、多信了什么、多会了什么？答不上来就不许写。

**第一步：盘家底——先审计原文材料利用率，不要急着动笔**

字数不够时，禁止立刻开始"凑"。先把本篇对应的原文章节过一遍，列一份材料清单：
- 案例 / 故事 / 人物（书里举了几个？）
- 数据、对比、图表结论
- 方法步骤、操作建议
- 反例、误区、作者的警告
- 金句、反常识观点

对照当前成稿，逐项标注：①已充分展开 ②一笔带过 ③完全没用。

**只要还有 ②③ 类的有料材料，优先从这里补**——这是最安全的方向，内容本来就在书里，不算新增事实。判断动作：挑 1 个没用上或只用过一句的案例/细节，把它扩写成 150~400 字的完整段落或小节（把案例里被省略的人物对话、心理活动、场景细节加回来），而不是往旧段落里塞一句话。

**第二步：找缺口——材料用完了，就从读者视角找"薄点"**

家底盘完还不够，逐段自问：读者读到这里会卡在哪？
- 概念第一次出现，解释清楚了吗，还是直接抛术语？（没解释就用生活化类比讲透："什么是权术？说白了就是……就像你在职场里……"）
- 例子只有正面吗？"反过来会怎样、踩坑的人长什么样"有没有？
- 方法停在"要重视 / 要坚持"这种空话吗，读者看完能照做吗？
- 论证跳步了吗——从观点直接蹦到结论，中间的推理链条补了没？
- 读者读到这里最可能问什么？（"真的假的""那我这种情况呢""会不会有例外"——预判到就主动解答："有人可能会说，这样做太圆滑了吧？其实不是……"）

**第三步：定方向——一次只补一个主题，严禁撒胡椒面**

- 选定一个最明显的缺口，集中写成 150~400 字的完整段落或一个小节；**禁止在全文各处零散塞碎句**（"真的""说白了""很重要"）
- 选缺口的标准：补完之后，读者那个"卡住 / 怀疑 / 不会做"的真实问题被解决了
- 补写方向优先级：**①原书未用材料扩写 → ②反例/对比/误区补充 → ③读者疑问预判与解答 → ④方法步骤细化拆解**（把"要勇敢"拆成"怎么勇敢？第一步……第二步……"）。按此顺序选，不从 ④ 倒着来

**第四步：红线自检**

每段补完立即过四问：
1. 删掉这段，读者会少知道什么？答不上来 = 注水，重写
2. 这段里的事实、数据、案例，书里有吗？书里没有的一律删
3. 是不是把上一段的意思换了个说法重复？是就删
4. 是不是"太重要了""值得深思"这种零信息量口号？是就删

字数还不够，**回到第一步重新盘**（这一轮材料状态已经变了），循环直到达标。

## 议题拆解方法

1. 通读该章，提取全部核心议题，数量即成稿小节数。
2. 每个议题按"案例 + 概念 + 方法"展开。
3. 排序：优先按章内逻辑；无明确逻辑时按"认知纠偏 → 行为方法 → 关系结果"。
