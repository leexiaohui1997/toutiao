# 配图提示词规范（本地 JSON 版）

## 硬性规格

- 封面图：2054x1600，每篇 1 张，存 article.json 的 `cover` 字段。
- 合集封面图：2054x1600，全书 1 张，存 overview.json 的 `collectionCoverPrompt` 字段。
- 插图：16:9，每 1~2 段一张，存 content 数组中 type=image 的块。
- 全部漫画/绘本/手绘插画质感，不使用写实或摄影风格。
- 禁止项固定写：水印、二维码、平台标识、乱码与额外文字。

## 封面图提示词模板

```
为今日头条科普文章生成封面图，比例2054x1600。主题"【章节主关键词】"：【与章节核心意象对应的场景，1~2句】。画面上方大字"【主关键词】"，下方小字"【N】个真相 越早懂越好"。漫画风格（绘本/手绘插画质感）；整体低饱和暖色调，大面积留白，情绪克制有故事感。禁止出现水印、二维码、平台标识、乱码与额外文字。
```

## 合集封面图提示词模板（overview.json 用）

```
为今日头条科普合集生成封面图，比例2054x1600。主题"【全书主关键词】"：【与全书核心意象对应的场景，1~2句，体现全书主题而非单章】。画面上方大字"【合集名称主关键词】"，下方小字"【全书价值主张】"。漫画风格（绘本/手绘插画质感）；整体低饱和暖色调，大面积留白，情绪克制有故事感。禁止出现水印、二维码、平台标识、乱码与额外文字。
```

## 插图提示词模板

```
【场景主体与动作】，【氛围/情绪】，漫画风格（绘本/手绘插画质感），比例16:9。禁止出现水印、二维码、文字乱码。
```

## 风格一致性

- 同一合集的封面、插图风格统一。
- overview.json 里写 `coverPromptTemplate` 与 `illustrationPromptTemplate`，后续各篇按此写作。
- 本篇封面若 `docs/{书名}/cover.png` 已存在，生图时以它为参考图 image_edit，保持视觉基调。

## 生图后替换流程

1. 按提示词逐张生图（seedream_5.0_flash），每张一张。
2. 保存：本篇目录下 `cover.png`、`插图1.png`、`插图2.png`……
3. 把 article.json 里 `cover` 字段改为 `./cover.png`；
4. 把 content 数组里对应 image 块的 content 改为 `./插图N.png`；
5. 此时 article.json 即可直接喂给 `pnpm dev edit --file <article.json>`。
